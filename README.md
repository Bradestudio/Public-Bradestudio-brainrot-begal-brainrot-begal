BRAINROT BEGAL — a 3D Roblox brainrot game set in a night market plaza. Absurd meme-born characters (Kucing Nasi Padang, Bakso Uranium, Raja Pasar Begal and 15 more originals) walk the conveyor earning nothing until you catch them: hold E to buy one, park it on your base, and it earns money every second. Climb six rarities (Biasa to Mitos) and three mutations (Emas, Pelangi, Berlian), lock your base or get robbed, slap thieves with F, outrun the Banjir Begal wave that sweeps the map every 100 seconds, and rebirth for a permanent x2 multiplier each time.

## Run it

```sh
rojo build default.project.json --output game.rbxl
```

Open `game.rbxl` in Roblox Studio to playtest and publish it as a Public experience.
